# 桥梁施工全景 3D 可视化系统（原型）

基于 Web 的桥梁施工 3D 可视化原型，支持 **BIM 模型导入、施工进度 4D 模拟、360° 全景漫游、构件信息查询**。

## 技术栈

- **Vite** + 原生 JS（ES Modules）
- **Three.js** — 3D 渲染与交互
- **web-ifc** — IFC（BIM）模型解析（WASM）

## 快速开始

```bash
npm install      # 首次：安装依赖（会自动复制 WASM 到 public/wasm）
npm run dev      # 启动开发服务器，浏览器打开 http://localhost:5173
```

生产构建：

```bash
npm run build    # 输出到 dist/
npm run preview  # 预览构建产物
```

| 全景漫游 | 顶部「🌐 全景漫游」切换；拖动查看四周，点击黄色圆环热点跳转机位 |

## 真实桥梁（来自桥梁统计表）

`src/data/bridges.json` 存放 4 座大桥的逐墩参数（柱径、墩高、桩径、桩长、盖梁、承台、桥台、系梁），
由 `scripts/parse-bridges.mjs` 从统计表解析而来。`src/realBridge.js` 据此生成三维结构物。

- 跨径按桥型布置图：卢福1号大桥 20m；其余三座 30m（各桥 `meta.span` 可改）。
- 上部结构按桥型布置图建模：预应力砼小箱梁（4 片/跨、先简支后连续），桥面净宽 11.5m。
- 纵坡与平面线形按布置图：中新大桥 -2.5%、右幅 R=4000 / 左幅 R=2940 右偏圆曲线；中兴大桥 -2%、直线；卢福1号 竖曲线（≈0 坡）、R=4950 右偏（左幅前 346m 为直线）；卢福2号 -2.8%、左幅 R=4950 右偏。
- 地形按墩高反推（高墩=深谷、矮墩=高台），还原"桥梁跨越山谷"的形态。
- **标高与地质**（来自《桥梁标高与地质数据》表）：墩顶/地面/桩底标高逐墩合入模型，地形沿真实地面线起伏、桩长按真实桩底标高；
  钻孔位置（"有地质柱状图"的墩）下方渲染**地质分层柱状体**，素填土/粉质黏土/全风化花岗岩/强风化花岗岩各用独立的程序化纹理，
  点「地质层」可开关，配合「地下剖面」查看，点击各层可查层顶/层底标高与承载力 fak。

重新解析表格：把 xlsx 先转成 markdown，再运行
`node scripts/parse-bridges.mjs <markdown路径> src/data/bridges.json`。

## 接入你的真实数据

### 1. BIM 模型（.ifc）

把你的 `.ifc` 文件拖进窗口即可，系统会自动解析并映射到施工分组（桩基/桥墩/桥台/主梁/桥面系）。
类型映射规则在 `src/ifcLoader.js` 顶部的 `TYPE_TO_GROUP` 中，可按你的模型类型调整。

### 2. 施工进度计划（每个构件独立排期）

编辑 `src/data/schedule.json`，`duration` 为总工期（天），`items` 数组里**每个构件一项**，用 `id` 唯一标识、`start`/`end` 指定独立起止时间：

```json
{ "id": "pier-1", "name": "桥墩 P1", "group": "pier", "start": 28, "end": 48 }
```

- `id` 必须与构件在 `src/bridgeModel.js` 中的 id 一致（如 `foundation-1`、`pier-2`、`girder-3`）。
- `group` 只用于甘特图配色归类，不影响排期。
- IFC 模型因 id 无法预先指定，会自动回退到按 `group` 聚合出的时间区间。
- `startDate` 为开工日历日期（第 0 天对应的日期），用于界面上的日期换算与显示。

**更简单的方式：直接在网页上改。** 点击任意构件，右侧信息面板底部会出现「施工排期」，
直接改「开工日期 / 完工日期」再点「保存排期」，3D 模型和甘特图即时更新，修改会保存在
浏览器本地（刷新不丢）；点顶部「重置排期」可恢复 `schedule.json` 的默认进度。

### 3. 全景照片

把你的 2:1 等距柱状投影全景图（jpg/png）放入 `public/panoramas/`，然后在
`src/data/panoramas.js` 中把对应机位的 `texture` 改为 `/panoramas/你的文件名.jpg` 即可。
未替换时使用程序化占位全景。

## 目录结构

```
bridge-3d-viz/
├── index.html            # 页面结构
├── src/
│   ├── main.js           # 入口：视图切换、时间轴、拾取、IFC 导入
│   ├── viewer.js         # Three.js 主场景（相机/灯光/地面/拾取）
│   ├── bridgeModel.js    # 程序化示例桥梁
│   ├── schedule4d.js     # 4D 进度控制器
│   ├── panorama.js       # 全景漫游（球体 + 拖拽 + 热点）
│   ├── infoPanel.js      # 构件信息侧栏
│   ├── ifcLoader.js      # IFC 解析与 Three.js 转换
│   ├── data/
│   │   ├── schedule.json # 施工进度计划
│   │   └── panoramas.js  # 全景机位配置
│   └── style.css
└── public/wasm/          # web-ifc 的 WASM 文件（npm install 时自动复制）
```
